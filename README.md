## Призначення

Програма читає CSV поступово, перевіряє записи студентів, фільтрує їх за групою та мінімальним балом, знаходить записи за ID або прізвищем. Обчислює середній, мінімальний і максимальний бал, кількість студентів у групах та вибирає найкращих N студентів. Дані також обробляються пакетами.

`sample.csv` містить 6 коректних і 4 некоректні записи. `students.csv` містить 100 000 згенерованих записів. Поля CSV: `student_id,first_name,last_name,group,average_grade`.

ID має бути додатним цілим числом, імена та група — непорожніми, бал — скінченним числом від 0 до 100. Некоректні записи пропускаються і підраховуються. У згенерованих даних ID унікальні. Для довільного CSV глобальна перевірка повторів ID не виконується, щоб не зберігати всі ключі в пам’яті.

## Запуск

Обробка 100 000 записів:

```powershell
.\.venv\Scripts\python.exe -m stream_processor.main
```

Перевірка на малому наборі:

```powershell
.\.venv\Scripts\python.exe -m stream_processor.main --path data/sample.csv --batch-size 4
```

Відбір за групою та балом:

```powershell
.\.venv\Scripts\python.exe -m stream_processor.main --path data/sample.csv --group ФЕП-32 --minimum 85 --limit 2 --batch-size 4
```

Параметри `--student-id` та `--last-name` задають пошук. `--limit` визначає кількість показаних записів та розмір вибірки найкращих студентів. `--batch-size` задає розмір пакета. Статистика всього файла виводиться перед результатами відбору.

## Експеримент

```powershell
.\.venv\Scripts\python.exe -m stream_processor.benchmark
```

Порівнюються eager та lazy на 10 000, 100 000 і 500 000 записів. Вимірюються повний час, пікова пам’ять і час до першого результату. Окремо виконується пошук ID 2 серед 1 000 000 записів. Генерування файлів не входить до часу обробки. Час і пам’ять вимірюються окремими запусками. `tracemalloc` показує Python-виділення пам’яті, а не всю пам’ять процесу.

Експеримент може тривати кілька хвилин. Eager-обробка мільйона записів потребує значного обсягу оперативної пам’яті. Тимчасові CSV видаляються після завершення. Результати виводяться лише в терміналі.
